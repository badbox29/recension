Take something out

Three different jobs, so three different files.

Compile a manuscript
One book as a single document — Word in standard manuscript format, EPUB to read on a phone, or plain text. For reading and sending. Not something you can import back.
Export this project
One project and everything in it: its books, scenes, cards, events and images, plus a readable folder of markdown. Can be imported again, here or on another account.
Back up everything
Every project you have, in one file. This is the one to keep somewhere safe.

Bring something in

Takes a backup or a project export — the .zip itself, or the recension-backup.json from inside one. The markdown files can't be imported: they carry no ids or ordering, which is what a restore needs.

Add what is missing
Inserts anything this device doesn't already have and changes nothing that's here, whatever the dates say. The default.
Replace everything
Deletes every project on this device first, then writes the file. Asks twice.

You'll see what the file contains, and choose between those two, before anything is written.
